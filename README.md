## Featured Projects

- **[AttendancePro](https://github.com/abhishekwadhwani2007/AttendancePro)**  
  Local-first biometric attendance system using real-time webcam facial recognition.
  - Implements OpenCV Haar cascades for face localization and a 30,000-dimensional flattened feature vector matched via Euclidean $k$-NN classification ($k=5$).
  - Built with CustomTkinter, local SQLite database persistence, and automated test coverage.
  - Packaged as a zero-dependency standalone Windows executable.  
  👉 *Read the architecture writeup: [Article on Medium](https://medium.com/@abhishekwadhwani06/from-spaghetti-code-to-software-architecture-my-year-long-journey-building-attendancepro-9e4e1849c41f)*

- **[CameraCoach](https://github.com/abhishekwadhwani2007/CameraCoach)**  
  Cross-platform Flutter mobile application providing real-time pose guidance against reference silhouettes with on-device pose estimation (Google ML Kit) and auto-capture at a 97%+ match threshold.
  - *Silhouette Engine:* **[body-outline](https://github.com/abhishekwadhwani2007/body-outline)** (standalone Python engine using MediaPipe pose landmarks, GrabCut contour refinement, and multi-layer neon glow rendering).
  - Resilient architecture with on-device fallback rendering (`SilhouetteGenerator`) when backend network is unreachable.
